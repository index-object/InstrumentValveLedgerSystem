# 仪表阀门台账管理系统 — 需求规格说明书

**版本**: 1.0  
**日期**: 2026-01-15  
**状态**: 初稿

---

## 1. 项目背景

化工、电力等流程工业企业中存在大量仪表阀门设备（调节阀、开关阀、压力表、温度计、流量计、液位计等），当前依赖 Excel 手工登记管理，面临数据分散、版本混乱、审批滞后、检修历史无追溯等问题。亟需一套数字化的台账管理系统实现设备全生命周期管理。

## 2. 项目目标

开发一套 B/S 架构的仪表阀门台账管理系统，实现设备信息的集中录入、分类存储、多维度检索、照片附件管理、审批流转及检修记录追溯，覆盖从一线员工填报到管理层审批的全业务流程。

## 3. 用户角色

| 角色 | 职责 | 核心权限 |
|------|------|----------|
| 员工 (employee) | 录入台账、提交申请 | 创建/编辑自己的台账，提交审批 |
| 班长 (leader) | 审批阀门申请 | 审批/驳回待审批项，查看全部数据 |
| 管理员 (admin) | 系统运维 | 全部权限，用户管理，系统设置 |

## 4. 功能需求

### 4.1 台账管理

- **台账合集**：以合集为单位组织阀门数据，支持创建、编辑、删除
- **阀门录入**：记录阀门基本信息、工艺条件、阀体规格、执行机构参数等
- **位号校验**：新建时自动检查位号唯一性
- **多类型支持**：调节阀、开关阀等不同类型拥有差异化字段
- **数据导入**：支持 Excel 批量导入（覆盖/跳过模式）
- **数据导出**：支持 Excel 格式导出

### 4.2 审批流程

- **提交审批**：草稿状态阀门可提交至审批
- **审批/驳回**：班长或管理员对待审批项进行审批操作
- **审批快照**：审批通过后生成状态快照，修改后本账号显示草稿、他人显示已审批
- **审批中心**：集中展示待审批/已审批/已驳回列表

### 4.3 附件与照片

- 阀门附件管理（定位器、过滤减压阀等组件信息）
- 现场照片上传与查看

### 4.4 检修记录

- 维护记录的新增、编辑、删除
- 按阀门关联查看检修历史

### 4.5 权限控制

- 基于角色 + 资源所有权的权限模型
- 我的台账（完整操作）vs 全部台账（只读）的上下文区分

### 4.6 系统管理

- 用户管理（增删改查、密码重置）
- 系统设置（审批模式切换等）

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 单表万级数据量下列表加载 < 2s |
| 响应式 | 支持 PC 端主流浏览器 |
| 安全性 | 密码哈希存储，登录会话管理，后端路由权限校验 |
| 部署 | 支持 Windows/Linux 单机部署，最小依赖 |

## 6. 约束与假设

- 项目采用 Python Flask 技术栈
- 数据库采用 SQLite，满足中小规模企业使用
- 前端基于 Bootstrap 5 + Jinja2 模板，不做前后端分离
