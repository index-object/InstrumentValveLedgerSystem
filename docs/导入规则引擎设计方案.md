# 仪表阀门台账管理系统 — 导入规则引擎设计方案

**版本**: 1.0  
**日期**: 2026-02-20  
**状态**: 初稿

---

## 1. 背景与挑战

动力班和化工班共 22 个 Excel 台账文件需要导入系统，文件格式不统一，面临以下挑战：

| 挑战 | 示例 |
|------|------|
| Sheet 名称不一致 | "就地压力" vs "就地压力表" vs "压力" |
| 列名不一致 | "设备等级" vs "设备分级" vs "仪表等级" |
| 列数不一致 | 温度 Sheet 少则 14 列，多则 30+ 列 |
| 标题行结构不一致 | 单行标题 vs 双行合并单元格标题 |
| 合并单元格 | "工艺条件" 下再拆子列 |
| 序号格式 | 整数 (1) vs 浮点数 (1.0) |
| 关联组件行 | 主阀门后跟多行附属组件（定位器、过滤减压阀等） |

## 2. 设计目标

- 无需改代码即可适配新文件格式
- 准确识别 10+ 种仪表类型
- 支持同义词列名自动匹配
- 过滤附属组件行，只导入主设备

## 3. 架构设计：三层规则引擎

```
源文件 → [Sheet识别层] → [列映射适配层] → [数据提取写入层]
```

### 3.1 仪表类型识别层 (Classifier)

三段式评分匹配，取最高分类型：

| 优先级 | 方式 | 权重 | 说明 |
|--------|------|------|------|
| 第一 | Sheet 名称精确匹配 | 10 | "调节阀" → control_valve |
| 第二 | 关键词 SS 匹配 | 7 | "压力表"、"远传压力" → pressure |
| 第三 | 列签名识别 | 5 | 检测特有列名如 "Cv值"、"分度号" |

### 3.2 列映射适配层 (Mapper)

通过同义词表将不同列名变体映射到统一标准字段：

```yaml
synonyms:
  位号: ["位号", "仪表位号", "设备名称/位号", "tag_no"]
  设备等级: ["设备等级", "设备分级", "仪表等级", "设备等级（A/B/C）"]
```

### 3.3 数据提取与写入层

- 自动检测单行/双行标题，处理合并单元格
- 序号为空的行标记为附属组件，写入关联表或跳过
- 类型转换、数据清洗、写入对应数据库表

## 4. 支持的仪表类型

| 大类 | 子类 | 目标表 |
|------|------|--------|
| 压力 | 就地/远传 | local_pressure_gauge / pressure_transmitter |
| 温度 | 就地/远传 | local_temperature / temperature_element |
| 流量 | — | flow_meter |
| 液位 | 就地/远传 | local_level_gauge / level_transmitter |
| 调节阀 | — | control_valve |
| 开关阀 | — | onoff_valve |
| 开关 | — | switch_device |
| 特殊仪表 | — | special_instrument |

## 5. 数据验证

导入完成后，与汇总表中各装置仪表类型数量进行对比校验，输出差异报告。
