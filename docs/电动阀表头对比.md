## 不同点

### 储运中心独有字段
- **功率KW** - 带单位标注
- **生产编号** - 用于追溯

### 动力中心独有字段
- **分级** - 设备分级
- **阀体** - 阀体信息
- **设备编号** - 内部编号
- **是否联锁** - 联锁状态

## 总结

| 对比维度 | 储运中心 | 动力中心 | 低位热 |
|----------|----------|----------|--------|
| 列数 | 16 | 22 | 29 |
| 字段完整度 | 基础 | 中等 | 详细 |
| 技术参数 | 简单 | 中等 | 详细（含材质、压力、温度） |
| 空列 | 无 | 有（3列） | 无 |
| 命名一致性 | - | - | 部分字段命名与其他文件不同 |

**主要差异：**
1. 低位热文件的技术参数最详细，包含材质、压力、温度等信息
2. 动力中心文件有3个空列，数据组织较松散
3. 字段命名存在细微差异（如"控制转矩Nm" vs "输出转矩Nm"、"转速r/min" vs "转速rmin"）
4. 储运中心文件最简洁，仅16列基础信息
